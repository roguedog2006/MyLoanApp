# Compliance & Legal Framework

## Before Launch Checklist

### Legal Requirements
- [ ] Consult fintech lawyer (jurisdiction-specific)
- [ ] Determine if lending license(s) required
- [ ] Understand interest rate caps (usury laws)
- [ ] Implement Truth in Lending Act (TILA) disclosures
- [ ] Draft Terms of Service + Privacy Policy

### KYC/AML Requirements
- [ ] Implement KYC verification (document + liveness)
- [ ] Integrate sanctions screening (OFAC, PEP lists)
- [ ] Set up customer data segregation
- [ ] Define data retention policy (typically 5-7 years)
- [ ] Create audit trail for all KYC events

### Payment & Security
- [ ] PCI DSS compliance (if handling cards)
- [ ] Encrypt sensitive data at rest + in transit
- [ ] Implement transaction monitoring/fraud detection
- [ ] Set up secure audit logging (immutable)
- [ ] Obtain cyber insurance

### Data Protection
- [ ] GDPR compliance (if EU users)
- [ ] Privacy policy aligned with regulations
- [ ] Incident response plan
- [ ] Regular security audits

### Operational
- [ ] Regular compliance training for team
- [ ] Documentation of all compliance measures
- [ ] Quarterly compliance reviews
- [ ] Third-party vendor vetting

## Recommended Third-Party Providers

### KYC/Identity Verification
- **Stripe Identity** - Easiest, built-in compliance
- **Onfido** - Enterprise-grade, 195+ countries
- **Jumio** - Strong selfie + document matching

### Payment Gateways
- **Stripe** - Best for most startups (2.9% + $0.30)
- **Wise** - Excellent for international transfers
- **Square** - Good US-focused option
- **Flutterwave** - Strong for Africa/emerging markets

### Compliance Tools
- **Stripe Radar** - Fraud detection
- **Unit** - Embedded banking for fintechs
- **Solarisbank** - European banking APIs
